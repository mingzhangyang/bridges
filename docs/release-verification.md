## 自动化证据

- `npm run check`：格式、语法、独立模块边界、98 个测试、静态构建通过。
- 欧拉求解与独立 DFS 对四顶点全部简单图的起终点组合一致；平行桥、两个断开的偶环、最后一步、非法起终点均有覆盖。
- 所有工程关的最小改建成本由第二套枚举和 DFS 行走验证，不只检查生成器自身的答案。
- 27 项浏览器场景通过；分别通过键盘与移动触摸桥廊走完 39 个可行主线 / 委托关；SB24 走独立的选择与解释流程，完成记录进入 discoveries。
- 桌面 1440px、手机 390px、窄屏 320px、844×390 横屏截图；无横向溢出。点击、稀疏拖动、重开、刷新、回放、保存失败、动态视图、快速操作与后台取消均通过。
- 普通动画停止后没有持续 rAF 请求；镜片动画使用有上限的计时器，撤销与后台切换不会留下输入锁。
- 本轮本地 Chromium 153 Linux 容器、6 倍 CPU 限速下，18,240 次模型提交平均约 0.0085ms，观察到的最大值 4.4ms。该数据是容器测量，不等同于真实手机性能；CI 使用 Playwright 锁定的 Chromium，原始 JSON 由 CI 附件提供。
- `test-results/browser-summary.json`、截图、明信片和 `model-performance.json` 为浏览器验收产物，CI 通过 artifact 保存。

## 2026-10-13 设计验收修复

- 把岸线布局与桥廊弯曲参数收敛到 `src/render/layouts.js`，历史城显式声明布局；候选桥在建设前后使用同一几何。横竖屏所有现有 / 候选桥均验证视口边界、无关陆地及岸线净空，覆盖 B—C 桥穿过 A 岛等问题。
- 拖动用完整轨迹持续缩小候选桥集合，允许平行入口在离岸后消歧，不再要求 75 单位以内识别。离开所有桥廊后不能在交叉处换桥，未消歧的完整轨迹在松手时显示选择卡。每桥双向独立验证，并通过触摸事件实际走通所有可行关。
- 第二层提示从当前残余图分析危险桥，标出会被隔断的未走桥，说明目的地、具体陆地与桥数。没有立即隔断风险时如实说明，第三层才推荐下一座桥。
- 历史教学直接标出原图的 14 个桥端，逐岛配成 5 对，留下 4 个端头；配套文字列出真实 edgeId，支持重看、减少动态和读屏。发现仍独立记录，不更改数学规则。
- 完成时短暂后退镜头并出现水面倒影；声景包括两步脚步、轻水声和完成铃声。没有持续动画或音频循环，撤销、重开、切关、后台取消会清理；异步音频激活也不能复活已取消的声音。
- 教学和回放的只读图不暴露交互数据标记，不与主舞台控件混淆。PNG 导出保留安静的倒影样式，默认仍隐藏路线。

本轮不更改关卡拓扑、edgeId、关卡 revision、每日排期或存档格式。已有路线与完成见证继续有效。真机与真人理解验收仍按以下门槛进行，不由自动化结果替代。

## 正式发布门槛

这些检查需要真人和真实设备，不能由模拟器替代：

1. iPhone Safari 和 Android Chrome 上核对拖动、桥选择、音频首次手势、分享与下载、屏幕旋转、后台恢复和私密模式保存提示。
2. VoiceOver / TalkBack 核对桥身份、目的地、已走状态、章节地图、工程按钮和对话框焦点；动态减少设置下切图与移动立即完成。
3. 在真实手机测量输入模型 <8ms 与完整交互体验，检查较复杂图的桥廊、桥头和交叉位置可读性。
4. 五位试玩者中四位在第一关理解“桥不可重复、陆地可重访”，三位在历史关后能解释无解；按反馈调整节奏与空间排布。
5. Cloudflare 预览 / 正式 origin 验证缓存、SEO、深链与回滚。验收完成后单独接入 games 外链。
